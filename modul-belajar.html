1. Instalasi Kabel UTP Straight (Standar TIA/EIA-568B)
Paket C - Aspek Fisik

Peserta diwajibkan membuat 2 kabel jaringan tipe Straight-Through menggunakan standar pengkabelan internasional T568B. Kabel ini menghubungkan port Ethernet Router ke Switch dan Switch ke PC Client.

Urutan pin konektor RJ-45 (T568B)

Hijau

Putih - Cokelat
8
Cokelat

Langkah Pengerjaan Praktik:

  1. Kupas kulit luar kabel UTP sepanjang 2 cm.
  2. Uraikan 4 pasang pilinan kawat dan luruskan secara rapi.
  3. Susun kawat secara sejajar dari pin 1 s.d. 8 sesuai urutan T568B.
  4. Potong rata kawat (sisakan panjang kawat terbuka sekitar 1.2 cm).
  5. Dorong kawat ke dalam konektor RJ-45 hingga seluruh ujung tembaga menyentuh dinding depan pin dan jaket luar kabel ikut masuk ke dalam badan konektor.
  6. Crimp dengan kuat menggunakan tang crimping.
Cara Membaca LAN Cable Tester:
Tancapkan kedua ujung kabel straight pada Master dan Remote tester. Nyalakan switch: Lampu LED nomor 1 s.d. 8 di kedua modul wajib menyala hijau secara bergantian dan berurutan. Jika ada lampu mati atau melompat, potong konektor dan crimp ulang.
2. Cisco Packet Tracer: Pasang Modul WIC-2T di Rack Router
Paket B - Hardware

Router Cisco seri 2811 secara standar hanya memiliki 2 port FastEthernet (Fa0/0 dan Fa0/1). Agar router memiliki port serial Serial0/1/0 sesuai perintah soal, pasang modul serial WIC-2T secara manual.

PENTING: Modul tidak dapat dipasang saat router dalam keadaan menyala! Matikan saklar daya sebelum memasang modul.

Tahapan Pemasangan Fisik:

  1. Pilih Router 2811 pada toolbar Packet Tracer. Beri nama Router-HQ dan Router-Branch.
  2. Klik fisik Router → Masuk ke tab Physical.
  3. Pada panel belakang router di sebelah kanan: Klik saklar daya hijau untuk mematikan daya.
  4. Pada daftar modul di sebelah kiri, klik modul WIC-2T.
  5. Tarik (drag and drop) modul ke Slot WIC 1 (slot kosong di bagian kanan atas).
  6. Klik kembali saklar daya untuk menyalakan router. Sekarang interface Serial0/1/0 telah aktif.
3. Cisco: Pasang Modul Wi-Fi WPC300N di Laptop & Setup AP
Paket B - Client Wireless

Di Packet Tracer, perangkat Laptop secara default hanya memiliki port kabel LAN RJ-45 (modul PT-HOST-NM-1CFE), sehingga tidak bisa menangkap sinyal radio dari Access Point. Siswa harus mengganti modul ke kartu wireless WPC300N.

Langkah Mengganti Modul Laptop ke Wi-Fi:
1. Buka Laptop → Tab Physical → Matikan saklar daya laptop (klik tombol power kuning).
2. Tarik modul port kabel LAN yang ada di bodi laptop ke arah daftar modul di sebelah kiri (untuk mencopotnya).
3. Tarik modul WPC300N dari daftar kiri ke slot kosong di bodi laptop.
4. Nyalakan kembali laptop. Masuk ke tab Desktop → PC Wireless → Tab Connect → Klik Refresh → Pilih SSID → Klik Connect.
Perbedaan SSID Kantor Pusat vs Kantor Cabang:
Agar perangkat tamu di Ruang Publik Jakarta tidak salah menyambung ke Access Point di Bandung, beri nama SSID yang berbeda:
• Access Point 0 (Jakarta): SSID = Hotspot-Jakarta • Terhubung ke port Fa1/1 Switch_HQ_ADM (VLAN 20)
• Access Point 1 (Bandung): SSID = Hotspot-Bandung • Terhubung ke port Fa1/1 Switch_BR_ADM (VLAN 20)

12. Mikrotik: Web Proxy, Filtering & Redirect
Paket C - Poin 16 s/d 19
Poin SoalParameter InputActionKeterangan
Poin 16 (Site) Dst. Host: *detik.com* deny Memblokir domain www.detik.com
Poin 17 (File) Path: *.mp3* • *.mkv* deny Memblokir unduhan file MP3 & MKV
Poin 18 (Konten) Path: *games* • Dst. Host: *games* deny Memblokir URL / Host yang memuat kata games
Poin 19 (Redirect) Dst. Host: *lionair.co.id* deny • Redirect: bnsp.go.id Mengarahkan lionair ke situs resmi BNSP
Penanganan Situs HTTPS & Protokol QUIC:
Web Proxy HTTP port 80 tidak dapat membaca lalu lintas HTTPS terenkripsi port 443.
1. TLS Host Filter: Tambahkan filter protocol=tcp dst-port=443 tls-host="*detik.com*" action=drop.
2. Drop QUIC (UDP 443): Browser Google Chrome di Android sering menggunakan protokol QUIC/HTTP3 lewat port UDP 443. Agar browser terpaksa beralih ke TCP (sehingga TLS-Host dapat membaca domain), tambahkan rule:
chain=forward protocol=udp dst-port=443 action=drop.
13. Dokumen Perencanaan: Gedung 4 Lantai & Analisis OSI
Bagian 1 - Teori & Analisis

Berdasarkan studi kasus PT. Teknologi Warungpedia: 1 Gedung 4 lantai, 8 ruangan (2 ruangan per lantai), masing-masing ruangan berisi 3 client workstation = Total 24 Client PC terkoneksi ke Proxy dan Mail Server.

Lapisan OSIPerangkat TerpasangKarakteristik & Analisis Performa
Layer 1 (Physical) Kabel UTP Cat5e, RJ45, Hub 8-Port Mentransmisikan sinyal elektrik biner. Cat5e mendukung bandwidth 1000 Mbps hingga 100 meter. Hub beroperasi dengan shared collision domain untuk kebutuhan pemantauan traffic.
Layer 2 (Data Link) Switch 24-Port, NIC Client, Wireless AP Meneruskan frame data berdasarkan tabel MAC Address. Setiap port switch membentuk dedicated collision domain mandiri (Full Duplex 1 Gbps), mencegah terjadinya tabrakan paket antarkomputer.
Layer 3 (Network) Router MikroTik, IP Routing Menangani logical IP addressing, pemisahan broadcast domain antarlantai, routing antarsubnet (LAN, WLAN, WAN), NAT Masquerade, serta filtering paket pada Firewall Filter.
