1. Instalasi Kabel UTP Straight (Standar TIA/EIA-568B)
Paket C - Aspek Fisik

Pada uji kompetensi Paket C, setiap peserta diwajibkan membuat 2 kabel jaringan tipe lurus (Straight-Through). Kabel ini digunakan untuk menghubungkan perangkat berbeda layer (Router ke Switch, atau Switch ke PC Client).

Langkah Pengerjaan Praktik:

  1. Kupas kulit luar kabel UTP sepanjang 2 cm. Hati-hati jangan sampai melukai isolasi kawat tembaga di dalamnya.
  2. Uraikan pilinan 4 pasang kabel, luruskan satu per satu hingga tidak ada kawat yang melengkung.
  3. Susun kawat secara sejajar dari kiri ke kanan sesuai urutan 1 s.d. 8 di sebelah kiri.
  4. Ratakan ujung kawat menggunakan pemotong tang crimping (sisakan panjang sekitar 1.2 cm).
  5. Dorong kawat masuk ke konektor RJ-45 hingga seluruh ujung tembaga menyentuh dinding depan pin RJ-45. Pastikan jaket luar kabel ikut masuk ke dalam badan konektor.
  6. Crimp dengan kuat menggunakan tang crimping hingga terdengar bunyi klik pengunci.
Cara Membaca LAN Cable Tester:
Kedua ujung kabel straight yang sudah dicrimp ditancapkan ke Master dan Remote tester. Nyalakan switch tester: Lampu LED nomor 1, 2, 3, 4, 5, 6, 7, 8 di kedua modul wajib menyala hijau secara bergantian dan berurutan. Jika ada lampu yang mati atau melompat urutannya, kabel wajib dipotong dan dicrimp ulang.
2. Cisco Packet Tracer: Pemasangan Modul WIC-2T di Rack
Paket B - Hardware

Router Cisco seri 2811 secara standar hanya memiliki 2 port FastEthernet (Fa0/0 dan Fa0/1). Agar router memiliki port serial Serial0/1/0 sesuai perintah soal, kita harus menambahkan modul antarmuka WAN.

PENTING: Di dunia nyata maupun di simulator Packet Tracer, Anda TIDAK BISA memasang modul jika router dalam keadaan menyala!

Tahapan Pemasangan Fisik:

  1. Pilih Router 2811 pada lembar kerja Packet Tracer. Beri nama Router-HQ dan Router-Branch.
  2. Klik perangkat Router → Masuk ke tab Physical.
  3. Perhatikan gambar panel belakang router di sebelah kanan: Klik saklar daya berwarna hijau untuk mematikan daya (lampu indikator mati).
  4. Pada daftar modul di sebelah kiri, klik modul WIC-2T (modul 2-port serial).
  5. Tarik (drag and drop) gambar modul ke Slot WIC 1 (slot kosong di bagian kanan atas).
  6. Klik kembali saklar daya untuk menyalakan router. Sekarang interface Serial0/1/0 telah tersedia dan siap dikonfigurasi.
3. Cisco: Konfigurasi WAN Cloud Frame Relay & Serial Inter-Router
Paket B - WAN

Jalur utama inter-router menggunakan network 10.10.10.0/24 yang dihubungkan melalui cloud Frame Relay.

A. Setting GUI di Cloud-PT (Jaringan WAN):

Cloud0 → Tab Config → Serial0: DLCI 101, Name A → Serial1: DLCI 201, Name B → Frame Relay: Connect Serial0 A ke Serial1 B

B. Konfigurasi Serial di Masing-masing Router:

PerangkatPerintah CLI SerialFungsi Perintah
Router-HQ (Jakarta) int se0/1/0
ip add 10.10.10.1 255.255.255.0
encap frame-relay
no sh 		Memberikan IP 10.10.10.1, mengaktifkan enkapsulasi Frame Relay, dan menyalakan interface.
Router-Branch (Bandung) int se0/1/0
ip add 10.10.10.2 255.255.255.0
encap frame-relay
no sh 		Memberikan IP 10.10.10.2 dan mengaktifkan enkapsulasi Frame Relay.
Mengapa Router Tidak Memerlukan Perintah "clock rate"?
Kabel serial memiliki dua sisi: DCE (penentu clock frekuensi) dan DTE (penerima sinyal). Pada skenario ini, sisi DCE terpasang di Cloud provider (tampak ikon jam pada kabel di sisi Cloud). Router bertindak sebagai DTE, sehingga perintah clock rate tidak boleh dipasang di router agar tidak terjadi bentrok clocking.
4. Cisco: Router on a Stick (RoAS), DHCP & RIP Routing
Paket B - Routing & VLAN

Router-on-a-Stick memungkinkan 1 kabel fisik fisik FastEthernet0/0 membawa traffic dari banyak VLAN sekaligus menggunakan enkapsulasi 802.1Q (Sub-interface).

Langkah Konfigurasi RoAS di Router:

int fa0/0 → no sh → int fa0/0.10 → encap dot1Q 10 → ip add 192.168.1.1 255.255.255.0 → int fa0/0.20 → encap dot1Q 20 → ip add 192.168.2.1 255.255.255.0
Konsep Exclude Address pada DHCP Server:
Sebelum membuat DHCP Pool, IP statis wajib dikeluarkan dari sebaran DHCP agar tidak terjadi duplikasi IP di jaringan:
• ip dhcp excluded-address 192.168.1.1 192.168.1.2 (Untuk gateway dan cadangan DNS)
• ip dhcp excluded-address 192.168.1.100 (Khusus untuk Server0 yang berjalan statis)
• ip dhcp excluded-address 192.168.2.1 (Untuk gateway VLAN 20)

Routing Dinamis RIP v2:

Kedua router mendaftarkan seluruh network lokal yang terhubung secara langsung (Classful summary network 10.0.0.0 dan network 192.168.x.0). Wajib menyertakan perintah version 2 dan no auto-summary agar subnet /24 tidak di-summarize menjadi /16.

11. Mikrotik: Web Proxy Access, Blocking Site, File & Redirect
Paket C - Poin 16 s/d 19

Web Proxy diaktifkan pada port 8080 dengan parameter cache administrator: nama_peserta@sekolah.sch.id. Seluruh traffic HTTP port 80 dari client diarahkan secara transparan ke proxy menggunakan aturan NAT Redirect.

Aturan Web Proxy Access (IP → Web Proxy → Access):

Poin SoalParameter InputActionKeterangan
Poin 16 (Site) Dst. Host: *detik.com* deny Memblokir domain www.detik.com
Poin 17 (File) Path: *.mp3* deny Memblokir unduhan file audio MP3
Poin 17 (File) Path: *.mkv* deny Memblokir unduhan file video MKV
Poin 18 (Konten) Path: *games* deny Memblokir URL yang memuat kata "games"
Poin 19 (Redirect) Dst. Host: *lionair.co.id* deny • Redirect to: bnsp.go.id Mengarahkan akses lionair ke situs resmi BNSP
Solusi Menghadapi Situs HTTPS (Mengapa Harus Tambah TLS-Host?):
Web Proxy tradisional hanya mampu membaca lalu lintas HTTP biasa (Port 80) karena data tidak terenkripsi. Pada situs HTTPS modern (seperti www.detik.com pada Port 443), data terenkripsi SSL/TLS sehingga Web Proxy tidak bisa membaca path URL.
Solusi Cerdas: Tambahkan aturan di IP Firewall Filter dengan parameter:
Chain: forward • Protocol: tcp • Dst. Port: 443 • TLS Host: *detik.com* • Action: drop.
Dengan trik ini, pengujian buka detik.com di HP maupun laptop dijamin 100% langsung terblokir di depan asesor!
12. Dokumen Perencanaan: Gedung 4 Lantai & Analisis Layer OSI
Bagian 1 - Teori & Analisis

Berdasarkan studi kasus PT. Teknologi Warungpedia: 1 Gedung dengan 4 lantai, 8 ruangan (2 ruangan per lantai), masing-masing ruangan berisi 3 client workstation = Total 24 Client PC terkoneksi ke Proxy dan Mail Server.

Lapisan OSIPerangkat TerpasangKarakteristik & Analisis Performa
Layer 1 (Physical) Kabel UTP Cat5e, RJ45, Hub 8-Port Mentransmisikan sinyal elektrik biner. Kabel Cat5e mampu mentransfer data hingga 1000 Mbps pada jarak 100 meter. Hub beroperasi dengan shared collision domain untuk kebutuhan pemantauan traffic sederhana.
Layer 2 (Data Link) Switch 24-Port, NIC Client, Wireless AP Meneruskan frame data berdasarkan tabel MAC Address. Setiap port switch membentuk dedicated collision domain mandiri (Full Duplex 1 Gbps), mencegah terjadinya tabrakan paket antarkomputer di 8 ruangan.
Layer 3 (Network) Router MikroTik, IP Routing Menangani logical IP addressing, pemisahan broadcast domain antarlantai, routing antarsubnet (LAN, WLAN, WAN), Network Address Translation (NAT Masquerade), dan packet inspection pada Firewall Filter.
