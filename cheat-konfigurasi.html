2. Analisis Kinerja Perangkat Berdasarkan Layer OSI

      

        
          
Lapisan OSIPerangkat TerlibatKarakteristik & Analisis Kinerja

        
        
          

            Layer 1 (Physical)
            Kabel UTP Cat5e, RJ45, Hub 8-Port
            Mentransmisikan bit sinyal elektrik. Cat5e mendukung bandwidth 1000 Mbps hingga 100 meter. Hub beroperasi secara shared collision domain untuk port monitoring.
          

          

            Layer 2 (Data Link)
            Switch 24-Port, NIC Client, AP
            Meneruskan frame data berdasarkan Hardware MAC Address. Setiap port switch membentuk dedicated collision domain mandiri (Full Duplex 1 Gbps), mencegah tabrakan data 24 client ke server.
          

          

            Layer 3 (Network)
            Router MikroTik, IP Routing
            Menangani pengalamatan IP, pemisahan broadcast domain, routing antarsubnet (LAN, WLAN, WAN), NAT Masquerade, serta filtering paket data pada Firewall Filter.
